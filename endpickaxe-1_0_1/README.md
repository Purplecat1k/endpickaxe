# End Pickaxe — читабельний вихідний код

Цей код відновлено декомпіляцією з `endpickaxe-1_0_0.jar` (v1.0.0), бо в самому
jar-і були лише скомпільовані класи з "intermediary"-мапінгом Minecraft
(імена типу `class_2680`, `method_58404`) — так виглядає будь-який готовий
Fabric-мод, підготовлений для розповсюдження. Тут ці імена повернуто до
людських (Yarn-мапінг 1.21.1): `BlockState`, `PlayerEntity`,
`getMiningSpeedMultiplier` і т.д., плюс додані коментарі.

## Що робить мод

Додає предмет **End Pickaxe** — єдиний інструмент, яким можна зламати
End Portal Frame (у виживанні). З невеликим шансом (~2%) з'являється як
бонусний лут у скринях End City.

## Структура

```
com/endpickaxe/
├── EndPickaxeMod.java          — точка входу мода: реєстрація предмета,
│                                  логіка ламання рамки портала (дроп блоку
│                                  + Ока Ендера, якщо було вставлене,
│                                  очищення сусідніх блоків порталу),
│                                  додавання предмета в лут-таблицю End City
├── item/
│   ├── EndPickaxeItem.java     — сам предмет (кирка на базі незеритового
│   │                              інструменту), прискорена швидкість копання
│   │                              та "придатність" саме для End Portal Frame
│   └── ModItems.java           — реєстрація предмета в грі + додавання
│                                  до творчої вкладки
├── client/
│   └── EndPickaxeClient.java   — клієнтська точка входу (поки що порожня,
│                                  зарезервована під майбутній клієнт-код)
└── mixin/
    └── EndPortalFrameBlockMixin.java
                                — робить End Portal Frame незламним для
                                  будь-чого, крім End Pickaxe; швидкість
                                  копання масштабується рівнем Efficiency

```

## Важливо перед компіляцією

Це **не готовий до збірки** проєкт (немає `build.gradle`, `gradle.properties`,
Fabric Loom тощо) — лише вихідні файли `.java` для читання й редагування.
Щоб зібрати з них робочий jar:

1. Візьми стандартний Fabric mod template (fabric-example-mod) під
   Minecraft 1.21.1 / Fabric Loader ≥0.16.0 / Java 21.
2. Заміни вихідний код у `src/main/java` цими файлами.
3. Перенеси решту ресурсів (`fabric.mod.json`, mixin-конфіги, assets,
   тексти/lang, моделі, текстури) з оригінального jar-а — вони не входять
   в цей архів, бо це не Java-код.
4. Перевір рядки з лут-таблицею End City в `EndPickaxeMod.java` — це
   найменш однозначна частина реконструкції (за сигнатурою байткоду), тож
   варто звірити з актуальним Fabric API перед фінальною збіркою.
