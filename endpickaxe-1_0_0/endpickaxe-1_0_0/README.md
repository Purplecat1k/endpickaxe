# End Pickaxe

A Fabric mod for Minecraft 1.21.1 that adds an End Pickaxe capable of breaking End Portal Frames.

Find it in End City and End Ship chests.

## Details

- **Mod ID:** `endpickaxe`
- **Minecraft version:** 1.21.1
- **Loader:** Fabric
- **License:** MIT

## Requirements

- Fabric Loader `>=0.16.0`
- Fabric API
- Java `>=21`

## Source note

This source was reconstructed by decompiling the compiled mod JAR, so variable

functionality is unchanged.
